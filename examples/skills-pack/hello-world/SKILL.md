# Hello World

A tiny starter skill. Use it to confirm your MCP client can load a skill pack
end to end before you write anything real.

## When to use

- You just wired up `mcp-skills-tool` and want to prove the connection works.
- You want a template to copy when authoring your first real skill.

## Instructions

1. Greet the user by name if you know it, otherwise say a plain hello.
2. Confirm which skill pack is loaded by naming this pack (`example-skills`).
3. Point the user at the other skills in the pack (for example, `code-review`).

## Example

> Hello! You're connected to the **example-skills** pack. Try the `code-review`
> skill next, or open `directory.json` to see how skills are declared.
